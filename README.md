# Fantastic Fist
Fantastic Fist, released in 2024 by 100th Coin, is a 2D platformer which uses both Keyboard controls to move the protagonist Vivi, and mouse controls to move a giant fist to interact with the environment.<br/>
# Fantastic-Fist-Archipelago-Client
An Archipelago Client for the game Fantastic Fist<br/>
Items include level gimmicks and coins.<br/>
Locations include coins, level exits, boss hearts, and tutorial panels.<br/>
The randomizer can be set up to have a more standard playthrough, or it can be set up to be open world.<br/>
# Setup
You will need:<br/>
Fantastic Fist: https://store.steampowered.com/app/2119470/Fantastic_Fist/<br/>
Archipelago: https://github.com/ArchipelagoMW/Archipelago/releases<br/>
Melonloader: https://melonwiki.xyz/#/<br/>
The Fantastic Fist Archipelago Client: https://github.com/DannySchultzDev/Fantastic-Fist-Archipelago-Client/releases<br/>
The Fantastic Fist AP World: https://github.com/DannySchultzDev/Fantastic-Fist-Archipelago-Client/releases<br/>
<br/>
Setting up the AP World:<br/>
Put the AP World in your custom worlds folder either manually, double clicking it, or using the "Install APWorld" option in the Archipelago Launcher.<br/>
Generate the options .YAML file by using the "Generate Template Options" option in the Archipelago Launcher.<br/>
Place the Fantastic Fist.yaml in your players folder.<br/>
Edit the options in the Fantastic Fist.yaml.<br/>
Generate the multiworld using the "Generate" option in the Archipelago Launcher. (It will be placed in your C:\ProgramData\Archipelago\output folder)<br/>
Upload the world to https://archipelago.gg/uploads, or unzip it and run the .archipelago to run it locally.<br/>
<br/>
Setting up the mod:<br/>
Open the MelonLoader Installer.<br/>
Select Fantastic Fist.<br/>
Install MelonLoader **7.1**. (Later versions will throw an error when trying to hook into the game)<br/>
Extract the files in the Fantastic Fist Archipelago Client zip.<br/>
Place the files in the zip in C:\Program Files (x86)\Steam\steamapps\common\Fantastic Fist\Mods.
Run Fantastic Fist, instead of seeing your save files you should see a connection screen. (Archipelago uses a normally unused 4th save file so you don't need to worry about losing your progress)<br/>
Input your connection information. (use arrow keys to move your selection and Enter to confirm)<br/>
Enjoy!
